# Archive: the kinds-of-work layer (30 September to 9 October 2026)

**Archived on 12 October 2026.** Yijie decided that the analysis must be built on the existing data alone: the original observation codes (PO, CLAR, CHECK, SEND, OTHER, REQ, DEC) in the five daily CSVs and the agreed purchasing stage of each record. The finer labels that were coded from the notes afterwards (the kinds of work K01 to K31), the causes drafted from them and the candidate evidence that rested on them are no longer used. The two notebooks were rebuilt on the original codes on 12 October; the [stage review of 12 October](../../measurement/Stage_Review_2026-10-12.md) records the agreed stages.

The files are kept because the figures reported on 7, 8 and 9 October rested on them. Each file keeps its original name and content; only the relative links inside the two Markdown files were updated when they moved here, so that they still resolve.

## What changed with the archive

The candidate figures of 9 October were defined on the kinds; the figures of 12 October are defined on the raw codes, so they differ:

| Candidate area | 9 October (kinds) | 12 October (raw definition) |
|---|---:|---:|
| Order and confirmation checking | 98 min (17.5%) | 91 min, the CHECK code (16.2%) |
| Request intake and validation | 94 | 121, the Specification stage |
| PO preparation / standard-review-manual | 111 | 165, the PO code |
| Maximalisatie | 43 | 73, PO rows whose note names MAX or added lines |
| Article/supplier data in Exact | 39 | 43, rows whose note names article or supplier data |
| PO supplier communication | 36 | 71, the SEND code |

The selection method did not change. With the raw evidence, two of the 28 scores changed (request intake: workload 3 to 4, repetition 2 to 3), so the provisional totals are now 76.2 (checking), 57.8 (request intake), 56.8 (article/supplier data) and 51.9 (maximalisatie), against 76.2 / 50.8 / 56.8 / 51.9 on 7 October. All of this stays provisional until Zhongxin's review.
